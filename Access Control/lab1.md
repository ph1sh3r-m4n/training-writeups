# Lab: Unprotected admin functionality

## LAB DESC

```
This lab has an unprotected admin panel.

Solve the lab by deleting the user carlos.
```

## SOLUTION

Use `robots.txt` file to see all the undisclosed paths in this case we find `/administrator-panel`.

We gain access to `admin` page via vertical privilege escalation and delete the user `carlos`.

> LAB SOLVED
